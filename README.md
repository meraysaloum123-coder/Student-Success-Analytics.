# Student Success Analysis & Institutional Reporting

## 📋 Overview
This project delivers a deep data-driven analysis of student success metrics, engagement levels, and dropout risks. It processes raw educational datasets to generate actionable strategic insights and professional executive reporting for senior management.

## 🗂️ Project Structure
- `analysis.py`: Main Python script for data processing, feature engineering, and metrics calculation.
- `Validated_Executive_Success_Report.md`: The complete markdown executive report.
- `Executive_Success_Report.pdf`: The official PDF report generated for management.
- `charts/`: Folder containing analytical visualizations (Correlation Heatmaps, Bar Charts, Line Plots).
- `Students.csv`: Primary dataset file.

## 🛠️ Tech Stack
- **Python 3.13**
- **Data Analysis:** Pandas, NumPy
- **Visualization:** Matplotlib, Seaborn
- **Reporting:** Markdown, PDF
